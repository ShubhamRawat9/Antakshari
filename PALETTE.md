# Antakshri Color Palette

The interface uses the palette supplied with the project update:

| Color | Hex | Usage |
|---|---|---|
| Cream | `#F1F3E0` | Page accents, score area, badge |
| Light Sage | `#D2DCB6` | Cards, gradients, soft backgrounds |
| Sage Green | `#A1BC98` | Highlights, focus states, decorative accents |
| Dark Sage | `#778873` | Primary buttons, headings, labels, score badge |

All primary UI colors are defined as CSS variables in `public/style.css` so they can be changed from one place.
